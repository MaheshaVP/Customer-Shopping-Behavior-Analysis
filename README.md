## Overview

An end-to-end Data Analytics project focused on analyzing customer shopping behavior using transaction data from 3,900 purchases. The project aims to uncover customer spending patterns, product preferences, subscription trends, and revenue drivers to support data-driven business decisions.

## Business Objective

The goal of this project is to answer key business questions such as:

- Which customer segments generate the highest revenue?
- Do subscribers spend more than non-subscribers?
- Which products perform best across categories?
- How do discounts influence customer purchases?
- What customer groups should businesses target for growth?

## Tech Stack

- **Python (Pandas, NumPy)** – Data Cleaning & Preparation
- **PostgreSQL** – Data Storage & Analysis
- **SQL** – Business Querying & Insights
- **Power BI** – Interactive Dashboard & Visualization
- **Jupyter Notebook** – Analysis Environment

## Project Workflow

Data Collection → Data Cleaning → Feature Engineering → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights

## Key Tasks Performed

### Data Preparation (Python)
- Cleaned and transformed raw data
- Handled missing values
- Standardized column names
- Created age-based customer segments
- Performed data quality validation
- Loaded cleaned data into PostgreSQL

### Data Analysis (SQL)
- Revenue Analysis by Gender and Age Group
- Customer Segmentation (New, Returning, Loyal)
- Subscriber vs Non-Subscriber Analysis
- Top Products by Category
- Discount Impact Analysis
- Repeat Customer Analysis
- Product Rating Analysis

### Dashboard Development (Power BI)
- Revenue KPI
- Customer Count KPI
- Customer Segmentation Analysis
- Product Performance Dashboard
- Subscription Insights
- Discount Analysis

## Key Insights

- Subscribers contributed higher overall revenue.
- Loyal customers generated the highest business value.
- Discount campaigns significantly influenced purchasing behavior.
- Customer spending patterns varied across age groups.
- Top-rated products consistently performed better in sales.
